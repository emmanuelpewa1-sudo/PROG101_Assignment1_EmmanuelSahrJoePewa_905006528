# Community Waste Reporting and Management System (CWRMS)

## PROG101 Assignment 1

### Project Overview

The Community Waste Reporting and Management System (CWRMS) is a proposed system designed to help residents report waste-related problems in Freetown, Sierra Leone.

The project applies programming logic and computational thinking to a community problem.

### Problem Description

Residents may encounter waste-related problems such as uncollected waste, overflowing waste bins, illegal dumping, and blocked drains containing waste.

The proposed system provides a structured way for residents to report these problems and for authorised operators to manage the reports.

### Proposed Solution

The system has two main parts:

1. **Resident Reporting Interface:** Allows residents to enter the location, category, and description of a waste problem. Residents may also attach a photograph.
2. **Administrative Management Interface:** Allows authorised operators to view reports, assign priorities manually, and update report statuses.

Each valid report receives a reference number and an initial status of Pending.

### Main Features

- Submit waste-related reports.
- Attach an optional photograph.
- Generate a report reference number.
- Record reports with an initial Pending status.
- View submitted reports.
- Assign High, Medium, or Low priority manually.
- Update report statuses.
